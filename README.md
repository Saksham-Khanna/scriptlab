# ScriptLab 🎬

**The Digital Writers' Room for the Next Generation of Storytellers.**  
ScriptLab is a production-grade web platform combining structured commercial screenwriting masterclasses, direct WGA mentor coverage, and interactive review workflows.

---

## 🚀 Key Features

- **Structured Masterclasses:** Step-by-step courses on commercial spec writing, TV showrunning, and structure.
- **Mentor Studio:** Dedicated dashboard for WGA mentors and instructors to manage review queues, grade assignments, and deliver professional coverage.
- **Student Dashboard:** Real-time progress tracking, pending assignments, recent feedback, and lesson bookmarks.
- **Admin Analytics:** Platform overview, user management, course catalog, and comprehensive audit logs.
- **Unified Vercel Architecture:** High-performance Next.js App Router with native Serverless API routes.

---

## 🛠️ Tech Stack

- **Frontend & Backend:** Next.js (App Router, Serverless API Route Handlers)
- **Styling:** Tailwind CSS, Custom Typography (Display fonts, dark cinema theme)
- **Authentication:** Secure Token & Cookie-based Auth (`scriptlab_token`)
- **Deployment:** Vercel (Production Live: [scriptlab-umber.vercel.app](https://scriptlab-umber.vercel.app))

---

## 📦 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Saksham-Khanna/scriptlab.git
   cd scriptlab
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
